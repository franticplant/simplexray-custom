### Changes

- **Toolchain:** Gradle 9.8, Android Gradle Plugin 9.4 with built-in Kotlin
  2.4, NDK r30. The app targets Android 16 (API 36) and compiles against API 37.
- **Dependencies:** Compose BOM 2026.09, AndroidX, gRPC 1.85 with
  protobuf-lite (smaller APK), OkHttp 5, LazyColumnScrollbar 3, Reorderable 3.
- **hev-socks5-tunnel 2.19.1.** The app now notices when the tunnel fails to
  start, and stops instead of reporting itself connected.
- **Geo data** updated to 202610210020; Xray-core v26.3.27 is now built with
  Go 1.26.10.
- **Fix:** saving or importing a config that has no `log` section no longer
  fails with "invalid config format".

### Build and release

- Releases are signed with a dedicated release key. They include
  `SHA256SUMS`, an SPDX SBOM and Sigstore attestations, and their builds are
  checked for reproducibility.
- CI checks license headers, formatting (ktfmt), unit tests and lint on every
  push and pull request.
