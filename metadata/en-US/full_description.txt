SimpleXray is a proxy client for Android built on Xray-core. It runs the official Xray-core executable as separate processes, rather than linking it into the app.

Features

- Xray-core in its own process: a core crash cannot take the app down, and the core runs at native speed.
- Several instances at once: one profile carries the VPN, and others run as local SOCKS/HTTP proxies. Each has its own statistics and its own start, stop and restart controls.
- Fast tunnel: hev-socks5-tunnel carries the device's traffic into Xray with low latency.
- Per-app routing, live traffic graphs, and import from share links.
- Material 3 interface with themed icons.

This is an independently maintained fork of lhear/SimpleXray. Releases are signed, reproducible, and carry build-provenance attestations.
